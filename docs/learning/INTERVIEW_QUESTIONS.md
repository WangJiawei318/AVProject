# 摸底题与面试题库

## 第 0 阶段基础摸底（2026-07-27）

请按 `1～12` 编号逐题回答。允许回答“不知道”，但请写出你当前的推理；不要查标准答案。导师收到后会逐题标记“正确 / 基本正确但不完整 / 理解有误”，不会因为一句“懂了”直接判定通过。

1. **C++ 对象与指针**：`MainWindow window;`、`MainWindow *p = new MainWindow;` 在对象存放位置、生命周期和释放方式上有什么区别？如果忘记 `delete p`，通常会发生什么？
2. **所有权与析构**：什么叫“对象所有权”？为什么一个类持有另一个对象的裸指针时，必须先问“谁负责释放”？请举一个你能想到的重复释放或悬空指针场景。
3. **智能指针**：`std::unique_ptr` 与 `std::shared_ptr` 的核心区别是什么？什么场景更适合 `unique_ptr`？`shared_ptr` 是否能自动解决所有内存和线程安全问题？
4. **线程基础**：进程和线程有什么区别？两个线程同时对一个普通 `int count` 执行 `count++`，可能出现什么问题，为什么？
5. **互斥锁**：互斥锁保护的是“代码”还是“共享数据/不变量”？如果加锁后在某个分支忘记解锁，会有什么后果？RAII 锁怎样降低这个风险？
6. **TCP**：TCP 保证了什么，又不保证什么？一次 `send(100KB)` 后，接收方是否一定能用一次 `recv` 得到完整 100KB？请解释。
7. **粘包与半包**：分别用自己的话解释粘包和半包。若协议采用“4 字节长度 + 包体”，接收端至少要维护怎样的处理步骤？
8. **epoll**：你目前怎样理解 `epoll`？它和“为每个客户端创建一个线程阻塞 `recv`”的模型相比，核心差别是什么？不知道 LT/ET 也可以如实说明。
9. **FFmpeg 基础**：`AVPacket` 和 `AVFrame` 分别代表什么？“解封装”和“解码”有什么区别？请尝试画出从 MP4/FLV 文件到屏幕像素的最短流程。
10. **音视频时间戳**：你听说过 PTS、DTS、time_base 吗？如果知道，请解释它们的用途；如果不知道，请说明你认为播放器为什么需要“时间”信息。
11. **Qt signal/slot**：signal/slot 解决什么问题？当发送者和接收者位于不同线程时，槽函数一定在发送信号的线程执行吗？你目前怎样理解？
12. **断点续传**：一个 1 GB 文件上传到 400 MB 时断线，重新连接后怎样安全确定从哪里继续？只相信客户端记录的 400 MB 有什么风险？至少说出需要双方核对的两项信息。
