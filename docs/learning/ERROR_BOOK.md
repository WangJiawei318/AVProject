## 记录原则

1. 只记录实际出现过的错误或关键遗漏，不把所有知识点重复抄入错题本。
2. “正确模型”必须同时包含通用概念与本项目源码实例。
3. 修正后安排至少一次变式题；只会背原答案不算消除。
4. 若源码本身存在缺陷，要区分“学习者理解错误”和“源码设计不足”。
