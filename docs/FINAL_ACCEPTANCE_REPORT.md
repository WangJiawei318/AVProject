# AVProject v1.0 最终验收报告

> 本报告依据阶段 1-10 开发记录及用户提供的人工测试结论整理。本轮仅审查源码和文档，没有由 Codex 重新执行 Windows/Ubuntu 端到端测试；标为“人工测试已通过”的项目来自用户验收结果。

## 1. 测试环境

- 项目：`D:\colin\project\AVProject`
- 客户端：Windows、Qt Widgets、MinGW、FFmpeg/SDL/OpenGL/OpenCV。
- 服务端：Ubuntu，IP `192.168.44.130`，默认端口 `8000`，g++/make/pthread/epoll/eventfd。
- 分片：64 KB；正式媒体 `AVServer/media/`；上传临时目录 `AVServer/temp/`；客户端缓存与任务状态位于 AVClient 运行目录相邻位置。

## 2. 客户端构建结果

阶段 1-10 记录及用户结论：AVClient clean build 与运行人工测试已通过。当前轮未重新执行 qmake/mingw32-make，未虚构新的构建结果。

## 3. 服务端构建结果

阶段 10 后 Ubuntu `make clean && make` 及运行人工测试已通过。当前轮处于 Windows 文档审查环境，未重新执行 Linux 全量构建。

## 4. 本地播放

状态：**人工测试已通过**。支持本地文件打开、暂停/继续、停止、seek、SDL 音频和 OpenGL 视频显示。

## 5. 本地录制

状态：**人工测试已通过**。支持桌面、麦克风与摄像头置顶预览，输出 H.264/AAC FLV。源码审查说明：摄像头当前未像素级合成进桌面输出。

## 6. Ping

状态：**人工测试已通过**。`PING_RQ/PING_RS` 可验证 Windows 到 Ubuntu 的 TCP 与协议链路。

## 7. 远程媒体列表

状态：**人工测试已通过**。服务端扫描 `media/`，客户端表格显示名称、大小、修改时间和扩展名。

## 8. 普通上传

状态：**人工测试已通过**。INIT/BLOCK/FINISH、64 KB 串行确认、正式文件重命名和列表刷新正常。

## 9. 普通下载

状态：**人工测试已通过**。INIT/BLOCK/FINISH、`cache/*.part` 写入与完成重命名正常。

## 10. 下载后播放

状态：**人工测试已通过**。下载完成后 `RemoteMediaPage -> MainWindow -> PlayerPage` 切页并播放 cache 文件。

## 11. 上传断点续传

状态：**人工测试已通过**。网络断开、客户端重启、服务端重启后可凭 transferId/token 从服务端安全偏移恢复；非法 token 与多客户端竞争已测试正常。

## 12. 下载断点续传

状态：**人工测试已通过**。网络断开及两端重启后可根据 `.part`、本地 JSON、远程 size/mtime 从非零偏移恢复；远程变化拒绝拼接。

## 13. epoll 多客户端

状态：**人工测试已通过**。epoll LT、每连接独立接收缓冲、非阻塞发送队列支持多连接 Ping、列表和传输并发。

## 14. 动态线程池扩容

状态：**人工测试已通过**。启动 4 个核心 worker，任务积压时最多扩到 8；队列有界为 256。

## 15. 动态线程池缩容

状态：**人工测试已通过**。非核心 worker 空闲 60 秒退出并回落到 4，finished thread 可回收/join。

## 16. 客户端任务期间断开

状态：**人工测试已通过**。Reactor 丢弃失效 connectionId 的 completion；上传解除活动绑定并保留可恢复状态，其他客户端不受影响。

## 17. 服务端重启

状态：**人工测试已通过**。上传扫描 `.task/.part` 恢复；下载因无状态可直接按 offset 继续。

## 18. 服务端关闭

状态：**人工测试已通过**。SIGINT/SIGTERM 唤醒 eventfd，线程池排空并 join，连接与 epoll/eventfd 释放，未出现人工测试中的挂死。

## 19. 已通过项目汇总

阶段 1-10 核心闭环均由用户确认人工测试通过：本地播放/录制、网络连接、媒体列表、普通与续传上传下载、下载后播放、多客户端 Reactor、动态线程池扩缩容、任务中断与服务端关闭。

## 20. 当前未支持/不承诺

- TLS、真实用户登录鉴权、ACL、数据库、配额。
- SHA-256 等强内容完整性校验。
- 在线边下边播、多任务客户端并行、通用暂停/取消、自动重试。
- 生产级协议兼容：当前 packed struct + 主机字节序。
- 生产级调度：无任务优先级、deadline、工作窃取和监控指标。

## 21. 最终结论

AVProject 已形成可构建、可运行、可演示的 v1.0 学习项目闭环，覆盖 Qt/FFmpeg 播放录制、TCP 应用层协议、epoll Reactor、动态业务线程池及双向断点续传。验收结论为：**核心功能人工测试已通过，适合作为源码学习和面试讲解项目；上述安全、完整性与生产化能力不在 v1.0 承诺范围内。**
